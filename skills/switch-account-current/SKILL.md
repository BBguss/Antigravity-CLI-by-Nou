# /switch-account-current

Show which account profile is active vs what files are live.

## Steps

1. Run: `sh ~/.gemini/antigravity-cli/profile-switch.sh current` (or `agy-switch current`)
2. Report the output briefly. If pointer and live differ, remind that a TUI
   restart applies the switch. Never print tokens.

Relay the script output verbatim; do not reformat it into your own tables or reinterpret addresses.
